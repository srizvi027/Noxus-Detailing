# Noxus Detailing — Next.js one-page site

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Edit everything in `data/content.js` (services, projects, reviews, contact info, socials, image paths).
Replace photos by overwriting files in `public/images/` (keep the same names) or change the paths in the data file.
Reviews are placeholders. The contact form is frontend-only (see TODO in `components/Contact.jsx`).
